# Sweden–Finland Overlanding — traveller roadbook

Live page: **https://ADAM.github.io/REPO/** (replace once Pages is enabled)

29-day self-driven 4x4 trip, 26 Sep – 26 Oct 2026. Four travellers, two vehicles,
Stockholm Arlanda round trip.

Tabs: **Legs** (day by day, with a "while here" list per base) · **Distance** ·
**Lodging** · **Things to do** · **Contingency**.

Day/night theme toggle, top right of the nav bar.

## Contents

- `index.html` — the whole roadbook, self-contained, no external assets or scripts
- `robots.txt` + `noindex` meta — asks search engines not to index the page
- `.nojekyll` — serve files verbatim, no Jekyll processing

## Note

⚠️ This page contains **live booking references, PINs and passenger names**.
GitHub Pages is public: anyone with the URL can read them, and a booking
reference plus PIN is enough to view or cancel a reservation. `noindex` only
stops search engines — it is not access control. Share the URL narrowly.

Source of record for the underlying research: the project folder
(`analysis/Base_Activities_Verified_v1.1.md`, `Bookings/Booking_Register_v6.0.md`).
